# Университеттің студенттерді тіркеу ақпараттық жүйесі

Бұл жоба университет студенттерін тіркеу және олардың мәліметтерін басқаруға арналған ақпараттық жүйе.

## Жобаның мақсаты

Студенттер туралы ақпаратты электронды түрде сақтау, жаңа студенттерді тіркеу және олардың мәліметтерін басқару.

## Негізгі мүмкіндіктер

- Жаңа студентті тіркеу
- Студент туралы ақпаратты көру
- Студент мәліметтерін өзгерту
- Студентті жүйеден жою
- Студенттер тізімін көру
- Жүйеге пайдаланушы аты мен құпиясөз арқылы кіру
